# 触发词模板

按阶段复制改写。`{{双花括号}}` 是你要填的地方。**这些是给使用者的示例，不是必须逐字使用的咒语。**

---

## Stage 1 · 知识库搭建

```
请把这个文件夹的品牌资料整理成知识库：

品牌资料文件夹：{{资料文件夹路径}}
品牌名：{{品牌名}}
落地位置：{{WorkBuddy 资料库 / Obsidian / 本地目录 / 钉钉 / 飞书}}
目标：整理成模块化知识库文档（品牌认知 / 产品技术 / 功效数据与合规 / 话术库 / 视觉规范），原始文件一并归档

开始前请先跟我确认文档结构和上传范围。
```

**常用变体**：

```
# 放 WorkBuddy 资料库，落地后要能问答
整理成知识库存到 WorkBuddy 资料库，建一个「{{品牌名}}知识库」文件夹挂进去，
建完后我要能直接问它问题。

# 放 Obsidian
整理成知识库写进我的 Obsidian vault（路径：{{vault 路径}}），
每篇加 frontmatter 和双链索引，品牌名错写变体写进 aliases。
```

## Stage 2 · 声量调研

```
请调研我的品牌 {{品牌名}} 在 {{平台组合，例：小红书、抖音、公众号}} 的社媒声量：

品牌词：{{品牌名及产品名，含常见错写}}
品类词：{{品类关键词，例：家用美容仪、超声提拉}}

用浏览器实抓站内搜索结果（品牌词 + 品类词），分析品牌声量、竞品占位、内容题型、舆情风险，
输出 HTML 交互调研报告。
```

> 若浏览器不可用：直接说明"改用公开页面 + 我提供的导出数据，并在报告里标注数据边界"。

## Stage 3 · 内容矩阵规划

```
基于品牌知识库和声量调研，帮我做 {{平台组合}} 的内容规划：

品牌知识库：{{知识库位置}}
要求：首月排到选题标题级 + 全年框架，含账号人设、内容支柱、标签 SEO、KPI 目标

开始前请确认规划周期和覆盖范围。
```

## Stage 4 · 成稿撰写

```
请把这条选题扩写成 {{平台}} 成稿：

选题：{{选题标题}}
内容依据：{{知识库文档或产品资料}}

按平台交付对应件套（小红书笔记五件套 / 抖音视频脚本六件套 / 公众号长图文 / Instagram caption 组 / TikTok 脚本组）。
```

## Stage 5 · 配图与海报

```
为这篇内容的配图出 gpt-image-2 生图 prompt：

内容/配图方案：{{成稿或配图方案}}
我有的素材：{{产品多角度图 + 模特持产品图，路径}}
落地位置：{{本地目录 / 网盘}}

先问我用哪种生图模式（A 打底叠字 / B 固定排版直出 / C 自由排版直出），
再按选中模式输出每张图的 prompt；需要时直接生成。
```

**成套海报时补一句**：

```
这是一套 {{N}} 张（封面 + 内页），请先锁定四项统一规范（logo 位置、字体、配色、风格），
每张 prompt 都写一遍，并把已完成的封面作为内页的风格参考图传入。
```

## Stage 6 · 多语言与海外延展

```
把这份中文素材做成 {{目标语言，例：日文 + 英文}} 版，发 {{目标平台，例：Instagram / TikTok / Facebook}}：

源素材：{{文案 / 视频脚本 / 海报 / 知识库文档}}
目标语言：{{中/日/英}}
目标平台：{{Instagram / Facebook / TikTok}}

按本地化（非直译）处理：日文用市场惯用词并精简 20-30%、遵守薬機法；英文用地道营销语；
海报替换图内文字并重排版式；最后做跨语言一致性核对。
```

---

## 组合调用（一次跑完多阶段）

```
我想给 {{品牌名}}（{{品类}}）做一轮完整的社媒启动：

1. 先把这个文件夹的资料整理成知识库（资料路径：{{路径}}，落地到 {{位置}}）
2. 调研它在 {{平台组合}} 的声量
3. 出一份内容规划（首月排到标题级 + 全年框架）
4. 出 {{N}} 篇成稿，{{平台}} 各一份
5. 每篇配 {{N}} 张图，先说清用哪种生图模式
6. 全部成稿做一份日文版发 Instagram

每完成一步先给我看，我确认再往下走。
```

---

## 只用一个阶段

这个 skill 的阶段是解耦的 —— 你已经有调研报告，可以直接跳到 Stage 3：

```
我已经有 {{品牌名}} 的声量调研（文件：{{路径}}），基于它做内容规划。
```

或者只要海报：

```
我只有产品图（{{路径}}）和这版文案（{{文案}}），给我做封面海报。
（agent 会先问模式，然后写 prompt、生成、核字）
```
